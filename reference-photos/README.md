# Reference Photos

Drop a reference screenshot/photo of each **original** EPro8 component into this folder.

## How to name each file

Name each image after the component's **ID** (the left column below), with any
common image extension: `.png`, `.jpg`, `.jpeg`, or `.webp`.

Example: the photo of the battery → `battery.png`

## What happens next

Once the photos are in this folder, tell me and I will:

1. Look at every image here and **redraw the matching component to look identical**
   to the original in the photo.
2. **Any component that does NOT have a photo here will be removed** from the
   simulator (palette, engine, everything).

So: only put photos here for the components you want to keep.
